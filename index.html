ClassMind — AI Teacher Assistant

RAG-based AI assistant for school teachers that generates lesson plans, quizzes, and concept explanations grounded in actual NCERT textbooks. Teachers upload any PDF — the system indexes it instantly and answers curriculum-aligned queries with traceable page citations.

  • End-to-end RAG pipeline — SentenceTransformers embeddings + FAISS vector search + Groq LLM inference
  • PDF ingestion with sliding window chunking (400 words, 80 word overlap) for semantic coherence
  • Chapter-aware hybrid retrieval — filters by chapter number when specified in query
  • Live PDF upload endpoint — indexes new documents into FAISS without server restart
